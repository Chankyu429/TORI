# C# - 박싱 (Boxing)

## 박싱(Boxing)이란?

박싱(Boxing)은 C#에서 값 타입(Value Type)의 값을 참조 타입으로 변환하는 과정이다.

---

## 박싱의 특징

- 값 타입을 참조 타입으로 변환한다.
- 값 타입의 데이터를 Heap에 객체로 생성한다.
- 객체에 값이 복사된다.
- 변환 과정에서 메모리 할당이 발생한다.

---

## 박싱 과정

```csharp
int value = 10;
object obj = value;
```

```text
int 값 10
   ↓
Boxing
   ↓
Heap에 객체 생성
   ↓
object가 객체를 참조
```

---

## 박싱이 발생하는 경우

- 값 타입을 `object`로 변환할 때
- 값 타입을 인터페이스 타입으로 변환할 때
- 값 타입을 참조 타입이 필요한 곳에서 사용할 때

---

## 박싱의 단점

- Heap에 객체를 생성한다.
- 메모리 할당이 발생한다.
- 값 복사가 발생한다.
- 반복적으로 발생하면 성능에 영향을 줄 수 있다.

---

## 결론

박싱(Boxing)은 값 타입의 값을 참조 타입으로 변환하여 Heap에 객체로 저장하는 과정이다.
