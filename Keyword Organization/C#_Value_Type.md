# C# - 값 타입 (Value Type)

## 값 타입(Value Type)이란?

값 타입(Value Type)은 변수에 실제 값을 직접 저장하는 데이터 타입이다.

---

## 값 타입의 특징

- 변수에 실제 데이터가 저장된다.
- 값이 복사될 때 데이터 자체가 복사된다.
- 일반적으로 Stack에 저장되지만, 실제 저장 위치는 사용 방식에 따라 달라질 수 있다.
- 다른 변수에 값을 복사해도 원본 변수에는 영향을 주지 않는다.

---

## 주요 값 타입

- **정수형** : `int`, `short`, `long`, `byte`
- **실수형** : `float`, `double`, `decimal`
- **문자형** : `char`
- **논리형** : `bool`
- **구조체** : `struct`
- **열거형** : `enum`

---

## 예시

```csharp
int a = 10;
int b = a;

b = 20;
```

```text
a = 10
b = 20
```

`b`에 값을 변경해도 `a`의 값은 변경되지 않는다.

---

## 값 타입과 참조 타입의 차이

| 구분 | 값 타입 | 참조 타입 |
|------|---------|----------|
| 저장 | 값 자체 | 객체를 가리키는 참조 |
| 복사 | 값이 복사됨 | 참조가 복사됨 |
| 예시 | `int`, `float`, `struct` | `class`, `string`, `array` |

---

## 결론

값 타입(Value Type)은 변수에 실제 값을 저장하는 데이터 타입으로, 값을 복사할 때 데이터 자체가 복사되는 특징이 있다.
