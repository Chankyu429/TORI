# CPU 시스템 버스 - 주소 버스 (Address Bus)

## 주소 버스(Address Bus)란?

주소 버스(Address Bus)는 CPU가 메모리나 입출력 장치에 접근할 때 사용할 주소를 전달하는 통로이다.

---

## 주소 버스의 특징

- 메모리 주소를 전달한다.
- CPU가 접근할 위치를 지정한다.
- 일반적으로 CPU에서 메모리 및 장치 방향으로 전달된다.
- 주소 버스의 비트 수에 따라 접근할 수 있는 메모리 공간이 결정된다.

---

## 주소 버스의 역할

- 메모리 주소 전달
- 데이터가 저장된 위치 지정
- 입출력 장치 주소 지정
- 메모리 접근 지원

---

## 예시

- **16비트 주소 버스** → 최대 `2^16`개의 주소 사용 가능
- **32비트 주소 버스** → 최대 `2^32`개의 주소 사용 가능
- **64비트 주소 버스** → 최대 `2^64`개의 주소 사용 가능

---

## 결론

주소 버스(Address Bus)는 CPU가 메모리나 입출력 장치에 접근할 위치를 지정하기 위해 주소 정보를 전달하는 통로이다.
