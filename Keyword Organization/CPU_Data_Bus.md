# CPU 시스템 버스 - 데이터 버스 (Data Bus)

## 데이터 버스(Data Bus)란?

데이터 버스(Data Bus)는 CPU, 메모리, 입출력 장치 사이에서 실제 데이터를 주고받는 통로이다.

---

## 데이터 버스의 특징

- 데이터를 전달한다.
- CPU와 메모리 및 입출력 장치 사이에서 사용된다.
- 양방향으로 데이터를 전달할 수 있다.
- 데이터 버스의 비트 수에 따라 한 번에 전송할 수 있는 데이터 크기가 결정된다.

---

## 데이터 버스의 역할

- CPU와 메모리 간 데이터 전달
- CPU와 입출력 장치 간 데이터 전달
- 메모리에서 데이터 읽기
- 메모리에 데이터 저장

---

## 예시

- **8비트 데이터 버스** → 한 번에 8비트 데이터 전달
- **16비트 데이터 버스** → 한 번에 16비트 데이터 전달
- **32비트 데이터 버스** → 한 번에 32비트 데이터 전달
- **64비트 데이터 버스** → 한 번에 64비트 데이터 전달

---

## 결론

데이터 버스(Data Bus)는 CPU, 메모리, 입출력 장치 사이에서 실제 데이터를 전달하는 통로이며, 일반적으로 양방향으로 데이터를 주고받는다.
