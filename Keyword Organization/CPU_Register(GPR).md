# CPU Register - General Purpose Register (GPR)

## General Purpose Register(GPR)란?

General Purpose Register(GPR)는 CPU Register의 한 종류로, 연산에 필요한 데이터나 주소를 임시로 저장하는 범용 레지스터이다.

---

## General Purpose Register의 특징

- CPU Register에 포함된다.
- 데이터와 주소를 임시 저장한다.
- 다양한 연산에 사용할 수 있다.
- CPU가 빠르게 데이터를 처리할 수 있도록 돕는다.

---

## General Purpose Register의 역할

- 데이터 임시 저장
- 산술 연산 수행
- 논리 연산 수행
- 주소 저장

---

## 활용 예시

- 덧셈, 뺄셈 연산
- 데이터 이동
- 함수 실행
- 변수 값 저장

---

## 결론

General Purpose Register(GPR)는 CPU Register의 한 종류로, 데이터와 주소를 임시 저장하여 다양한 연산을 빠르게 수행할 수 있도록 하는 역할을 한다.
