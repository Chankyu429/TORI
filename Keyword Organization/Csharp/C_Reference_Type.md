# C# - 참조 타입 (Reference Type)

## 참조 타입(Reference Type)이란?

참조 타입(Reference Type)은 변수에 실제 데이터가 아닌 객체가 저장된 메모리의 참조(주소)를 저장하는 데이터 타입이다.

---

## 참조 타입의 특징

- 변수에 객체에 대한 참조가 저장된다.
- 여러 변수가 같은 객체를 참조할 수 있다.
- 객체는 일반적으로 Heap에 생성된다.
- 참조가 복사되면 같은 객체를 가리킨다.

---

## 주요 참조 타입

- **클래스** : `class`
- **배열** : `array`
- **문자열** : `string`
- **인터페이스** : `interface`
- **델리게이트** : `delegate`
- **객체 타입** : `object`

---

## 예시

```csharp
int[] a = { 1, 2, 3 };
int[] b = a;

b[0] = 10;
```

```text
a[0] = 10
b[0] = 10
```

`a`와 `b`가 같은 배열 객체를 참조하기 때문에 `b`의 값을 변경하면 `a`에서도 변경된 값을 확인할 수 있다.

---

## 값 타입과 참조 타입의 차이

| 구분 | 값 타입 | 참조 타입 |
|------|---------|----------|
| 저장 | 값 자체 | 객체에 대한 참조 |
| 복사 | 값이 복사됨 | 참조가 복사됨 |
| 주요 저장 영역 | 사용 방식에 따라 다름 | 객체는 일반적으로 Heap |
| 예시 | `int`, `float`, `struct` | `class`, `string`, `array` |

---

## 결론

참조 타입(Reference Type)은 변수에 객체 자체가 아닌 객체에 대한 참조를 저장하며, 여러 변수가 하나의 객체를 공유하여 사용할 수 있는 데이터 타입이다.
