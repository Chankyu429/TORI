# CPU 시스템 버스 (System Bus)

## 시스템 버스(System Bus)란?

시스템 버스(System Bus)는 CPU, 메모리, 입출력 장치 사이에서 데이터와 정보를 전달하는 통신 통로이다.

---

## 시스템 버스의 특징

- CPU와 메모리 및 입출력 장치를 연결한다.
- 데이터를 주고받는 통로 역할을 한다.
- 여러 종류의 버스로 구성된다.
- 컴퓨터 내부의 정보 전달에 사용된다.

---

## 시스템 버스의 종류

- **데이터 버스(Data Bus)** : 데이터를 전달한다.
- **주소 버스(Address Bus)** : 데이터가 저장되거나 읽힐 메모리 주소를 전달한다.
- **제어 버스(Control Bus)** : 읽기, 쓰기 등 제어 신호를 전달한다.

---

## 시스템 버스의 역할

- 데이터 전달
- 메모리 주소 전달
- 제어 신호 전달
- CPU와 장치 간 통신

---

## 결론

시스템 버스(System Bus)는 CPU, 메모리, 입출력 장치 사이에서 데이터, 주소, 제어 신호를 전달하는 통신 통로이며, 데이터 버스, 주소 버스, 제어 버스로 구성된다.
