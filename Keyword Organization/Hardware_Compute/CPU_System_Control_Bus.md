# CPU 시스템 버스 - 제어 버스 (Control Bus)

## 제어 버스(Control Bus)란?

제어 버스(Control Bus)는 CPU, 메모리, 입출력 장치 사이에서 데이터의 읽기와 쓰기 등의 제어 신호를 전달하는 통로이다.

---

## 제어 버스의 특징

- CPU의 제어 신호를 전달한다.
- 메모리와 입출력 장치의 동작을 제어한다.
- 읽기 및 쓰기 신호를 전달한다.
- 시스템의 동작을 조정한다.

---

## 제어 버스의 역할

- 메모리 읽기 제어
- 메모리 쓰기 제어
- 입출력 장치 제어
- CPU와 장치의 동작 조정

---

## 주요 제어 신호

- **Read** : 데이터를 읽도록 제어
- **Write** : 데이터를 쓰도록 제어
- **Interrupt** : CPU에 인터럽트 발생을 알림
- **Clock** : 동작 타이밍을 전달

---

## 결론

제어 버스(Control Bus)는 CPU, 메모리, 입출력 장치 사이에서 읽기, 쓰기, 인터럽트 등의 제어 신호를 전달하여 컴퓨터 시스템의 동작을 조정하는 역할을 한다.
