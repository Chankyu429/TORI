# CPU Register - Stack Pointer (SP)

## Stack Pointer(SP)란?

Stack Pointer(SP)는 CPU Register의 한 종류로, 현재 스택(Stack)의 최상위(Top) 메모리 주소를 저장하는 레지스터이다.

함수 호출, 지역 변수 저장, 함수 종료 시 스택의 위치를 관리하는 데 사용된다.

---

## Stack Pointer의 특징

- CPU Register에 포함된다.
- 스택의 최상위 주소를 저장한다.
- 함수 호출 및 복귀 시 값이 변경된다.
- 지역 변수와 매개변수를 관리한다.

---

## Stack Pointer의 역할

- 스택 주소 관리
- 함수 호출 지원
- 함수 복귀 지원
- 지역 변수 및 매개변수 관리

---

## 활용 예시

- 함수 호출(Call)
- 함수 종료(Return)
- 지역 변수 저장
- 매개변수 전달

---

## 결론

Stack Pointer(SP)는 CPU Register의 한 종류로, 스택의 최상위 메모리 주소를 저장하여 함수 호출과 복귀, 지역 변수 및 매개변수를 효율적으로 관리하는 역할을 한다.
